# Poser 物理诊断

先阅读项目 [物理验证说明](../../docs/poser/physics-validation.md)，按问题选用其中的离线入口。

- STATIC Avatar / inverse bind 决定参考骨长、朝向和局部位置。LIVE 状态供恢复或明确标注的观察使用。
- 合并旧测试前核对其模型轴约定；历史 Basis A/B 的 `S=I` 不能覆盖当前 FK 的 `S=Ry(pi)`。重复历史冲突先比较对应文件树，保留远端独有证据与本地后续实现。
- 骨段代理、最终局部 TRS 蒙皮、连续性和实机视觉是不同证据。常规 CTest 通过不能覆盖实际动作失败。
- 出现“乱跳”时，先分离积分、身体接触、自碰撞及根修正阶段的局部变化，再改变求解器。
- 检查最终写回的 FK 几何；Bullet 内部未合回的刚体位置不能代替最终蒙皮。
- 布面拉伸使用源三角形的实际边和四权重，不以代理质心连线替代。接触梯度须包含整棵 FK 后代与固定权重，并用独立有限差分验证。
- 同位置、同权重的顶点只构成接缝候选；缺少部件或邻接证据时不自动缝合重叠衣层。
- 检查子步动画父链；逐骨世界位置插值会缩短转身中的骨段，局部插值须保留明确的动画平移。
- 胶囊的轴向转动影响运动学速度与摩擦。用 STATIC 局部轴继承骨骼参考标架，避免每步从世界轴构造时产生不连续。
- STATIC 相交只对应确切的三角形对，不能豁免整片衣物与其他身体面的新增相交。
- 新解析的长度、布局或函数入口须来自对应版本的实际消费者。不能把本机研究 RVA、原始粒子字节或未解码字段推广成通用协议。
- 对完整动作和既有夹具进行验收后才更新交付入口。失败实验留在忽略的临时目录，停止时记录失败指标和原因。

复用 `scripts/poser/export_static_fixtures.py` 整理现有 JSON；它只读文件，不打开或启动游戏。
若已有完整采集，先离线验证，避免反复要求用户重新采集。新角色问题优先检查层级、蒙皮和参与范围，不堆叠角色名例外。

对照 Endfield-Poser 时阅读 [原生任务与模拟表面对照](../../docs/poser/endfield-physics-reference.md)，区分可复用原则、资源适配和当前游戏尚未核验的接口。

更改 FK / IK 采样语义时更新 `MotionDriverVersion`；更改物理求解语义时更新 `Version`，分别核对缓存失效。
具体构建和测试记录写入当前调查报告；可复用经验更新说明文档，单次会话路径、PID、哈希及失败实验脚本不进入本 skill。
