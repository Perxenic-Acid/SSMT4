# Mod 管理刷新维护

适用于 Mod 管理加载、启停、分组切换和预览闪烁问题。

- 先核实实际调用链：当前页面在 `ModsManagement.vue` 内实现刷新，不要仅凭名称修改未调用的 watcher 文件。
- 已有内容刷新使用完整快照一次提交，按去除 DISABLED 前缀后的身份复用对象；首次空列表仍可分批呈现。
- 根目录流式扫描需同时检查刷新代次、游戏、分组加载代次和当前分组，避免覆盖用户刚切换的分类。
- 区分 content 与 structure 变更；普通启停不得清空全游戏预览或更新所有图标版本。
- 预览失效保留旧内容，成功后替换；失败保留可重试标记。目录重命名后的图片地址需就绪再交接。
- 加载提示不能占据列表布局空间。列表动画避免与卡片 hover 或 Vue FLIP 同时操作 transform。
- 验证：`bunx vue-tsc --noEmit`、`node --test scripts/tests/test-mod-snapshot.mjs`，并在应用中检查大库启停和连续切换分类。
