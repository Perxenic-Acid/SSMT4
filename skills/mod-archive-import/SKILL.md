---
name: mod-archive-import
description: 修改 SSMT Mod 管理页的拖拽、多选导入、加密压缩包密码交互及解压重试时使用。
---

入口在 `src/views/ModsManagement/ModsManagement.install.ts`；后端预览、安装分别是 `preview_mod_archive` 和 `install_mod_archive`，解压算法在 `ssmt_compress_utils.rs`。

- 预览与安装都可能遇到加密；两个阶段必须传同一密码并处理重试。只识别 `ARCHIVE_PASSWORD_REQUIRED`、`ARCHIVE_PASSWORD_INVALID`，文件损坏、路径错误或磁盘写入错误不能一概当成密码错误。
- 批次密码只保存在局部内存，普通文件不清除它；不同密码解密失败时再询问。取消只跳过当前文件，保留之前可用密码继续批次，结束后释放密码，不写日志或设置。
- 批次开始时固定游戏与目标分组；拖入分组对整批生效。文件、目录选择器都支持多选并复用同一批量入口。
- 解压失败后由安装暂存事务清理，再接受密码重试，不能将半解压目录提交到 Mods。ZIP 不能静默跳过加密条目；7z 的两遍读取都必须传密码。
- 回归入口和验证边界见 `docs/mod-archive-import.md`。旧批次延迟隐藏进度不能覆盖新批次。

- 导入结束仅刷新目标分类及新增子树的索引，当前列表按身份合并，保留已有卡片和分析订阅；不走全库结构刷新、不切回根分类、不启用页面级 loading。批次必须汇总失败文件名和原始错误，不能只记录控制台或仅显示成功数。

- 同名目标由后端返回 `MOD_IMPORT_CONFLICT`，单文件与批次均提供覆盖、跳过、重命名、直接写入。覆盖保留禁用备份；直接写入在解压完成后合并，保留其他文件并覆盖同名文件，不沿目标链接写入。解压事务仍完整，直接写入阶段的 IO 失败可能已有部分文件更新，错误须明确说明。新 Rust 参数需要重启 `bun tauri dev`。

- Windows 安装出现拒绝访问时先区分解压与最终目录移动。移动失败可有限重试并在独占创建的新目标中复制回退；禁止借回退覆盖已有目标。诊断复用 `file_locks`，不要把错误 5 一律称作占用，不自动终止进程或放宽 ACL。真实 ZIP 临时解压诊断入口见文档。
