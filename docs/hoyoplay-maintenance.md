## 参考基线

本机只读参考 Starward `433dc28a`（MIT）与 FufuLauncher `62adc64`（MIT）。
主要对应 HoYoPlayClient / GamePackageService、Sophon.proto，以及
SophonBuildClient / GameServerConverter / GameChannelSdkService。
两者不作为 SSMT 运行时依赖，SSMT 独立实现 Rust 后台与 Vue 入口。

2026-10-22 读取官方接口确认：旧 `getGamePackages` 给原神返回 5.5.0，但
`getGameBranches` / Sophon Build 返回 7.1.0；崩铁和绝区零的旧压缩包接口也落后。
因此不能以旧 ZIP 包作为当前安装更新基线，更不能用其覆盖已有新客户端。
使用官方当前分支及其可用的预下载分支，不凭日期推测预下载是否已开放。

预下载只写 SSMT 下载缓存，不提前替换正在运行的客户端。更新及换服需游戏关闭，
所有目标文件验证完成后再提交版本和渠道；未知 Mod、注入器及第三方文件不整体清理。
下载和解压不在 Tauri 交互线程执行。本轮开发不下载完整游戏，也不修改本机真实游戏。

## 入口与操作

- 没有可用的游戏进程路径时，主页点击“启动游戏”先自动匹配现有客户端。仍未找到则
  进入安装界面；主按钮下方“已安装? 点击此处手动指定”可以直接选取 exe。
- 查询到本地正式版本落后时，主按钮变成“更新游戏”，点击直接开始后台更新。
  网络检查失败时保留普通启动，不伪造“必须更新”。
- 官方提供预下载分支时，主按钮左侧显示无背景的“预下载”按钮。点击直接开始，
  不弹确认、不导航、不启动游戏；显示进度与暂停操作，主启动按钮保持可用。
- 主页进入、重新获得焦点和每三分钟异步检查版本。查询不会自动发起任何下载。
- “游戏设置 → 游戏管理”提供目录、语音、更新 / 修复、预下载、恢复和原神换服。
  安装使用空的游戏目录，不使用 3DMigoto 的 `installDir`；成功后写入 `targetExePath`。
- 原神换服只处理客户端渠道。跨国服与国际服复用经校验的分块，转换程序和数据路径，
  下载相应渠道 SDK。原客户端须先更新到目标渠道当前正式版本。
- 未声明渠道的旧配置需要在管理界面明确确认所选渠道；不根据崩铁 / 绝区零同名 exe
  自动猜测国服。语音选择会合并游戏中已安装的语音，不提供卸载语音功能。

## 文件与恢复边界

`src-tauri/src/hoyoplay/` 为独立后端模块，`src/features/gameMaintenance/` 为独立界面
与主页状态逻辑，便于后续拆成可选页面。没有修改 Native / Runtime、插件 ABI 或渲染路径。

所有大型任务在 `spawn_blocking` 中执行，最多四个文件工作线程。单次只允许一个维护任务，
同一客户端目录还有跨进程文件锁。暂停保留已验证分块与暂存文件，下次执行同一操作即可续用。
预下载在游戏运行时也可进行，不能因其存在而拒绝启动；更新、换服、恢复要求游戏关闭。

游戏目录的 `.ssmt-maintenance/` 包含：

| 内容 | 用途 |
| --- | --- |
| `owner.json` / `lock` | 确认目录归属与互斥，拒绝接管未知同名目录 |
| `cache/` | 压缩块与 `.part` 断点，按块身份和摘要区分 |
| `manifests/` / `sdk-*.zip` | 已校验的资源清单及渠道 SDK，重试时复用 |
| `stage/` | 完整校验过的新文件 |
| `backup/` / `journal.json` | 提交前的文件摘要、原文件备份及应用配置变更 |
| `completed.json` | 已提交的清理记录，避免清理中断被误当成更新失败 |

下载阶段不改原文件；提交前再次检查原文件和暂存文件摘要。文件占用导致提交失败时尝试恢复。
进程在提交时中断，下一次启动游戏会提示先到游戏管理恢复。恢复前检查全部相关文件；若玩家
之后改过文件，停止恢复并保留备份。不要自行删除 `journal.json` 或 `backup/` 绕过检查。
首次安装中断且目标路径尚未保存时，在管理界面重新选择原安装目录，再点击“恢复原客户端”。

资源路径拒绝越界、Windows 特殊名称、大小写冲突以及链接 / junction。渠道 SDK ZIP 同样
检查路径、链接、大小和重复文件。旧文件只在官方旧清单 / SDK 证明归属且摘要未变时移除，
不递归清理未知文件。应用配置只合并本模块拥有的三个字段，保留其他设置。

## 交付验收

建议先使用独立的客户端副本，按原神、崩铁、绝区零逐项记录渠道和版本。

1. 无游戏路径且匹配不到客户端：主按钮进入安装，下面小字能选已有程序。
   配置了有效路径时保持启动行为；绝区零两种图形预设均识别。
2. 安装到空目录，选择语音，确认进度更新且其他页面可操作。下载中暂停后重新开始，
   验证缓存复用；完成后检查目标 exe、`config.ini`、语音记录与 SSMT 目标路径，再实际启动。
3. 使用落后的客户端副本：主页显示“更新游戏”，不能误走启动。更新完成后恢复启动文案，
   实际进入游戏，检查所选及原有语音、普通 Mod 和插件组合。
4. 官方开放预下载时：按钮出现在启动左侧，点击不弹窗、不打开设置、不切换页面，
   进度可见，仍可启动当前客户端。预下载前后客户端文件摘要和版本不变。
5. 原神在同一正式版本测试国服 → B服 → 国服、国服 → 国际服 → 国服，检查 SDK 与 exe，
   SSMT 目标随之更新；未知 Mod 和自定义文件保留。账号与游戏内区服不作迁移。
6. 在测试副本中用文件占用模拟提交失败，确认恢复原版本并说明原因。需要检验进程中断恢复
   时仅对副本操作；恢复前故意修改某个目标文件，应拒绝覆盖并保留备份与记录。
7. 无网络、预下载尚未开放、磁盘不足、配置渠道不明时，应给出对应状态，不能卡住界面。

## 当前限制

使用 Sophon 分块复用和下载，尚未实现 HPatch / LDiff；更新下载量可能大于官方增量补丁。
提交采用完整新文件暂存，空间需求会高于原地打补丁，提前检查空间并保留失败现场。
预下载分块在正式更新成功后清理，本轮没有添加通用缓存管理页面。
本轮未完成完整客户端下载与实机游戏验收；崩坏3不在首批支持范围。
