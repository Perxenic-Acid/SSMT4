# 界面布局维护记录

- 切换游戏立即清空分类树、子分类、Mod 卡片、计数、搜索和导航历史，同时使分组加载、刷新与启动任务失效。同游戏刷新可保留列表，跨游戏不可复用可见列表。`mod_library_stream_scan` 的每条事件携带调用方的 `scanId`，监听器同时校验请求身份、游戏和刷新代次，防止新游戏监听器收到旧游戏全局事件；异步懒加载还校验游戏切换代次，覆盖 A→B→A。前端回归直接执行页面流式扫描函数，交错发送两个游戏分块和最终结果。

- 分类树默认全部收起，不恢复上次会话保存的展开记录；切换游戏也清空展开键。当前浏览过程中手动展开的分支可在数据更新或结构重建时保留，避免重新弹出；定向导航到子分类仍可展开必要路径。

- 分类树采用 Element Plus `lazy` / `load`，箭头依据后端 `hasChildGroups` 和已有子分类判断，不把所有未加载分类当作可展开。后端磁盘扫描、流式扫描、SQLite 缓存读取均按同一目录分类规则检查直接子分类，不把 Mod 内部目录计入。缓存元信息更新后同步内部节点的叶子标记，避免必须重建才能更新箭头。展开/收起只更新展开记录，不切换右侧内容；失败使用 reject 允许重试。默认展开键负责恢复后续加载的深层节点，不手动展开虚拟根节点。跨游戏加载结果应丢弃，加载标记按游戏清空。

- 分类切换、缓存命中及子项加载不得调用 `bumpGroupTree()`。该函数通过 `v-if` 和 key 销毁整棵树，再逐项恢复展开状态，会造成子项反复弹出。树数据用 `ModsManagement.tree.ts` 按 ID 原位同步：不仅保留节点对象，也保留根数组及各级 children 数组，避免 Element Plus `TreeStore.setData()` 重建内部节点。重排和结构刷新仍可显式重建，切换游戏以游戏 key 隔离实例。`node --test scripts/tests/test-mod-snapshot.mjs` 覆盖真实 Element Plus TreeStore 的节点身份、展开/选中状态与子项增删。

- Mod 管理分类树的纵向间距只由 `.el-tree-node__content` 的 34px 行高和 2px 行间距决定。展开子容器不设纵向 margin，避免按需加载得到空分类后留下 8px 空白；自定义节点固定 30px 高，图标边框计入尺寸，避免内部内容挤出行框。保留 Element Plus 原有展开/收起动画，选中和悬停只过渡颜色、背景和阴影。验证时覆盖无图标、有图标、空分类、多级分类及连续切换。

- Element Plus 下拉项的横向溢出在 `src/styles/glass-dropdown.css` 统一处理：弹层裁切到边框，滚动区域限制到可用视口宽度，列表清除默认外边距。排查时同时检查下拉框的内联 `width` / `min-width`，只给选项文字设置省略号无法约束整行选中背景。手动验证短编号、长文本、窄窗口及滚动列表，并检查悬停和选中背景未越过弹层。

- 游戏管理作为游戏设置子页，沿用浮窗的卡片背景、12px 圆角、标题字号和按钮样式，不重复显示页面大标题。
- 设置侧栏每个页签都提供同尺寸图标。预下载入口只在所选渠道已经确认可用时出现，未知和暂无均隐藏。
- 主页资讯和版本标签共用左下布局列。资讯图片独立保留比例，不依赖加载完成后的固有尺寸。
- 贴图标记左列的 LOD、DrawIB 与 Component 悬停区域使用圆角；Component 整行裁切与外层圆角一致。
- 工作台提取页签从内容左缘排列，继承页面字体，统一为 13px；指定 IB Dump 标题与侧栏标题使用同等字号与字重。
  提取页签不使用逐项毛玻璃和圆角底板，避免两块凸起背景与下划线重叠。
- 主页版本行仅并排显示 SSMT 与游戏 3DMigoto 包版本，不再提供 SSMT Runtime 标签。

Mod 管理刷新保留已有卡片直至完整快照就绪，根目录扫描不能覆盖正在浏览的分类。加载提示悬浮显示，不推挤列表；普通启停只失效相关分组预览，预览重新读取失败时保留旧图。卡片更换图片地址时等待新图就绪，列表进出使用透明度动画，避免位移与卡片自身效果叠加。

其他页面首次加载时内容出现突兀仍待后续处理，本轮不修改公共加载或进场动画。
