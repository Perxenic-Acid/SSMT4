# 界面布局维护记录

- 游戏管理作为游戏设置子页，沿用浮窗的卡片背景、12px 圆角、标题字号和按钮样式，不重复显示页面大标题。
- 设置侧栏每个页签都提供同尺寸图标。预下载入口只在所选渠道已经确认可用时出现，未知和暂无均隐藏。
- 主页资讯和版本标签共用左下布局列。资讯图片独立保留比例，不依赖加载完成后的固有尺寸。
- 贴图标记左列的 LOD、DrawIB 与 Component 悬停区域使用圆角；Component 整行裁切与外层圆角一致。
- 工作台提取页签从内容左缘排列，继承页面字体，统一为 13px；指定 IB Dump 标题与侧栏标题使用同等字号与字重。
  提取页签不使用逐项毛玻璃和圆角底板，避免两块凸起背景与下划线重叠。
- 主页版本行仅并排显示 SSMT 与游戏 3DMigoto 包版本，不再提供 SSMT Runtime 标签。

Mod 管理刷新保留已有卡片直至完整快照就绪，根目录扫描不能覆盖正在浏览的分类。加载提示悬浮显示，不推挤列表；普通启停只失效相关分组预览，预览重新读取失败时保留旧图。卡片更换图片地址时等待新图就绪，列表进出使用透明度动画，避免位移与卡片自身效果叠加。

其他页面首次加载时内容出现突兀仍待后续处理，本轮不修改公共加载或进场动画。
